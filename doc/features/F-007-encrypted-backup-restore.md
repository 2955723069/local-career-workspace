# F-007 — 加密轻量/完整备份与原子导入

实现轻量和完整备份格式、Web Crypto 加密、版本/概览预览、重复 ID 检测、逐项冲突选择和事务化导入。轻量备份排除原始 PDF/DOCX，完整备份包含原始文件；两者都排除 API Key、通知授权、临时 AI 上下文和发送预览。使用 PBKDF2 派生密钥和 AES-256-GCM，每次导出随机 salt/IV，密码不保存。导入在任何解密、校验、冲突选择取消或提交失败时整体回滚，默认不覆盖本地数据。

## Acceptance criteria

- [ ] 轻量备份可被解析且不含原始文件；完整备份包含所有原始 PDF/DOCX Blob 及轻量备份数据。
- [ ] 导出使用 Web Crypto PBKDF2 和 AES-256-GCM，每次导出 salt 和 IV 均随机且不同，密码不持久化。
- [ ] 导入先输入密码并展示版本和数据概览，再检测相同 ID，逐项支持保留本地、使用备份或导入新副本。
- [ ] 错误密码、损坏文件、格式校验失败、冲突取消或写入异常均不改变任何已有本地数据。
- [ ] API Key、通知授权、临时 AI 请求上下文和发送预览在两种备份中均不存在。
- [ ] 成功导入一次性提交并可在刷新后读取；重复导入不会静默覆盖本地记录。

## Test cases

- [ ] BR-TC-1: 导出轻量和完整备份并检查文件清单，确认 Blob 仅出现在完整备份。 (来源: §6.7；§8 备份与隐私 B1)
- [ ] BR-TC-2: 连续两次使用同一密码导出，salt 和 IV 均不同且可正确解密。 (来源: §6.7)
- [ ] BR-TC-3: 导入含重复 ID 的备份，逐项选择本地/备份/副本后预览结果与选择一致。 (来源: §6.7；§8 备份与隐私 B4)
- [ ] BR-TC-4: 使用错误密码或损坏文件导入，断言导入前后的本地数据快照完全一致。 (来源: §3 可恢复；§7；§8 备份与隐私 B2)
