# T-F004-2 — 集成面试日历、提醒反馈和复盘界面

将上一任务的面试、复盘、提醒和 ICS 服务接入现有原生 TypeScript 应用入口。新增面试管理区域，允许从职位详情创建同一职位的多轮面试，编辑开始/结束时间、面试时区、类型、地点或链接、面试官、提醒和备注；提供日、周、月三种日历视图，并在每条记录上提供改期、取消、完成、编辑和导出 ICS 操作。所有展示时间必须使用记录自身 timezone。新增 InterviewReview 编辑面板，支持评分、问题及回答、优缺点、观察信号、薪资讨论、下一步和私密备注的保存与再次编辑。处理 Notification.permission 状态和通知失败状态，拒绝或浏览器关闭时显示可感知的应用内提醒与 ICS 操作提示。遵循现有组件和 CSS 模式，保证表单标签、键盘焦点、aria 状态、窄屏换行和错误/保存状态反馈。

## Acceptance criteria

- [ ] 应用入口加载后可看到日历区域和创建面试表单；同一职位可连续创建至少两轮面试并在日历中分别显示。
- [ ] 日、周、月视图切换只改变当前展示范围；面试标题、公司、职位、当地时间、时区、状态和提醒信息可读且不会遮挡操作控件。
- [ ] 改期、取消和完成按钮调用对应服务并刷新视图；改期后新时间可见，旧时间线事件仍可从职位详情查看。
- [ ] 通知未授权、被拒绝、浏览器关闭或通知失败时，界面显示明确状态，应用内提醒列表和 ICS 导出按钮仍可用。
- [ ] 复盘面板可创建和编辑全部 InterviewReview 字段，保存后显示待复盘/已复盘状态，取消编辑不会改变已保存数据。
- [ ] UI 测试覆盖创建跨时区面试、三种视图、改期/取消/完成、通知回退、ICS 下载入口和复盘编辑，并验证关键控件具备语义标签和键盘可操作性。
