# F-006 — OpenAI 兼容 AI 顾问与发送确认

实现本地 AI 设置、连通性测试、职位级 AiConversation、请求上下文组装、预览确认、错误重试、结果展示和报告导出。支持 API 地址、模型名、API Key、可选组织 ID及自定义请求头；Key 只存当前浏览器且不得写入备份。发送前展示当前简历版本、简历文本长度、JD 长度、对话消息数和目标地址；取消、缺配置、非法地址、连通性失败或请求失败时不得外发，并保留本地资料及已保存对话。系统提示强制真实性约束，建议不得覆盖原始简历。

## Acceptance criteria

- [ ] 设置可保存和编辑 OpenAI 兼容 API 配置并执行连通性测试；API Key 不出现在日志或备份中。
- [ ] AI 请求预览准确显示简历版本、两类文本长度、消息数和目标 API 地址，未确认前不发送。
- [ ] 用户取消预览、配置缺失、地址非法、连通性失败或请求失败时，网络请求不包含简历/JD，已有资料和对话保持不变并可重试。
- [ ] 不同 applicationId 的对话严格隔离；支持追问、单段复制、全部复制和优化报告导出。
- [ ] 输出包含匹配概览、问题、建议、原文/改写对照、待补充信息和风险提示，并将建议标记为建议。
- [ ] 系统提示和 UI 明确禁止虚构经历、技能、学历、成果或数字；AI 结果不会修改或覆盖原始 PDF/DOCX。

## Test cases

- [ ] AI-TC-1: 未确认发送预览时断言没有发出请求，预览字段与当前数据一致。 (来源: §6.6；§8 匹配与 AI M3)
- [ ] AI-TC-2: 缺少 Key、非法地址或用户取消时请求计数为零且本地对话未改变。 (来源: §6.6；§7)
- [ ] AI-TC-3: 为两个职位发送消息后分别读取，确认消息不会串线。 (来源: §4.5；§8 匹配与 AI M4)
- [ ] AI-TC-4: 模拟返回虚构经历的建议，UI 显示真实性风险并确认原始文件文本未被修改。 (来源: §3 诚实建议；§6.6)
