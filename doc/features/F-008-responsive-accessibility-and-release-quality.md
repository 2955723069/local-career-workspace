# F-008 — 响应式可访问性、隐私状态与发布质量

对全部页面补齐桌面和移动端布局、横向阶段切换、底部操作区、长文本换行/截断、键盘焦点、语义化表单标签、屏幕阅读器状态和可感知错误/保存/通知/AI 外发状态。补充隐私说明、敏感信息脱敏日志、删除确认、主要业务端到端测试、生产构建检查和 README（安装、启动、离线、备份、恢复、通知、AI、清除数据）。生产构建不得包含测试文件、原始依赖目录或 API Key。

## Acceptance criteria

- [ ] 桌面端主要流程可并排使用看板、列表和日历；移动端为单列并支持横向阶段切换和底部操作区。
- [ ] 窄屏下长文本、文件名、公司名和职位名可换行或截断，操作控件和状态提示不重叠。
- [ ] 主要操作可仅用键盘完成，焦点可见，表单有语义化标签，保存/错误/通知/AI 状态可被屏幕阅读器感知。
- [ ] 错误、权限拒绝、保存中/已保存、AI 外发中/失败和可重试状态均有明确反馈且不泄露敏感内容。
- [ ] 桌面和移动端端到端测试覆盖上传简历、创建职位、绑定简历、本地匹配、面试、复盘、备份和恢复主流程。
- [ ] README 覆盖安装、启动、离线核心流程、备份恢复、通知限制、AI 配置和清除本地数据；生产构建通过敏感信息扫描。

## Test cases

- [ ] RQ-TC-1: 在桌面和移动视口运行主流程，确认布局、阶段切换和底部操作区可用且无重叠。 (来源: §6.8；§8 工程质量)
- [ ] RQ-TC-2: 使用键盘和屏幕阅读器语义检查完成表单与操作，确认焦点和状态提示可感知。 (来源: §6.8)
- [ ] RQ-TC-3: 执行端到端主流程并验证离线模式仍能完成本地核心步骤。 (来源: §3 本地优先；§8)
- [ ] RQ-TC-4: 构建生产包并扫描测试文件、依赖目录和 API Key 字符串，确认均未包含。 (来源: §8 工程质量)
